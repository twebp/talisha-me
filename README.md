# My Design Portfolio Website 

Welcome to the repository for my professional design portfolio. This website showcases my work as a Product Designer, highlighting my end-to-end UX/UI process, interactive prototyping, and clean front-end execution.

* **Live Website:** [👉 Click here to view my live portfolio](https://twebp.github.io/talisha-me/)

---

##  Tech Stack & Architecture

I built this portfolio to demonstrate my ability to translate high-fidelity designs into pixel-perfect, interactive code.

* **Design Framework:** Designed completely in Figma utilizing a custom atomic design system.
* **Front-End Layout:** HTML5, CSS3, Flexbox/Grid
* **Interactivity:** Vanilla JavaScript for smooth scrolling, case study filtering, and theme toggling.
* **Hosting & Deployment:** Hosted via [GitHub Pages / Vercel / Netlify] with automated Git deployments.

---

## Key Design & Code Features

* **Mobile-First Responsive Design:** Optimized breakpoints ensuring a seamless reading experience on mobile, tablet, and desktop monitors.
* **Accessibility Focused:** Checked contrast ratios against WCAG AA standards and utilized semantic HTML for screen readers.
* **Performance Tuned:** Images optimized and compressed to ensure fast load times and rapid case-study rendering.
